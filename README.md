# Contactly – Contact Management System

A modern contact management web application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add new contacts
- Edit existing contacts
- Delete contacts
- Live search
- Favorites section
- Form validation
- Local Storage persistence
- Toast notifications
- Responsive desktop interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
